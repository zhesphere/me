# TASK-002｜探索区以下内容系统重构与博客域名迁移

## 分发信息

- 来源：`PROJECT_HUB.md`
- 执行模型：`GPT-5.6 Terra / Medium`
- 状态：COMPLETED
- 优先级：P0
- 发布：完成验收后按持续发布规则自动部署

## 目标

保留已通过的首屏视觉基线，重新设计“继续探索”以下全部内容，使文章、个人方向和关于信息形成连续的编辑叙事，而不是三个普通卡片区块。将所有博客链接、RSS 和回退文章统一迁移到 `https://blog.orbitvo.com/`，不再引用旧域名。

## 已验证事实

- `https://blog.orbitvo.com/` 返回 HTTP 200。
- `https://blog.orbitvo.com/rss.xml` 返回 HTTP 200 和 XML。
- 旧博客域名当前无法建立 TLS 连接，不能继续作为任何运行时或回退链接。
- 下半页目前由三张同构入口卡、等权文章列表和圆形 ZS 关于图组成，层级重复、留白和视觉节奏单一。

## 设计方向

1. 删除“从这里开始”的三张入口卡，不重复首屏已有 Blog / GitHub 行动。
2. 第一段改为编辑型“最新信号”：最新文章为高权重主条目，另外两篇形成节奏不同的次条目；标题是视觉主体，编号和日期退居辅助层。
3. 第二段建立“创造坐标”：以硬件、软件、AI、设计等真实兴趣交叉关系表达个人方向，不制作虚假项目墙或技能进度条。
4. 关于区改为大字号宣言、克制的人格介绍和两个清晰外链；ZS 图形只作构图锚点，不再像默认头像占据半屏。
5. 页脚与段落之间增加连续的轨道切线、序号和留白节奏，但功能文字不得低于 12px，正文桌面不低于 16px、移动端不低于 15px。
6. 动效限于轻微上浮、光线和轨道变化；内容在无 JavaScript与减少动态模式下完整可读。

## 允许修改

- `src/pages/index.astro`
- `src/styles/global.css`
- `src/data/site.ts`
- `src/data/blog-fallback.json`
- 与内容、域名和回归验收直接相关的测试及文档

## 不做

- 不推翻已通过的首屏构图，仅允许调整“继续探索”衔接。
- 不添加虚构项目、履历、邮箱、联系表单、统计数字或第三方 UI/动效库。
- 不修改主域名、Vercel 项目、DNS 或博客仓库。
- 不开始 P3 的独立高级动效扩展。

## 验收

1. 仓库中运行时、配置、测试和公开文档不再出现 `blog.zsphere.top`。
2. 构建时能够从新 RSS 获取文章，网络失败时回退链接也指向新域名。
3. 类型检查、单测、生产构建和 E2E 全部通过。
4. 在 360、768、1440 和超宽屏检查下半页；无横向滚动、卡片挤压、孤字或重复入口。
5. 键盘可以依次访问所有文章和外链，焦点清晰；减少动态模式不持续播放装饰动效。
6. 完成后归档本任务、更新中枢、提交推送、等待 Vercel 成功，并验证 `orbitvo.com` 的新版内容与 `blog.orbitvo.com` 链接。
