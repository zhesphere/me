## 任务目标

把当前“暗、散、第一眼不知道看哪里”的首屏重构为一个强视觉焦点。访问者应先看到品牌主张，再自然找到“阅读博客”，最后理解 GitHub 与下方内容入口。

## 已知问题

1. `--muted-dark: #65708a` 被用于导航辅助信息、眉题、坐标、系统状态和视觉标注，多个文字尺寸只有 `7–11px`，在 `#080b14` 上阅读压力过大。
2. 左侧标题、右侧轨道球体、顶部 `ONLINE`、年份、坐标和多个英文标签同时争夺注意力。
3. 轨道视觉是最亮的对象，却与核心标题和主要操作分离，形成“好看但不知道做什么”的首屏。
4. 首屏已有博客和 GitHub 按钮，下一屏又出现三张入口卡，信息重复。
5. 当前测试只验证元素存在、链接和不重叠，没有验证字号、对比度、首屏主次和关键操作可见性。

## 设计指令

### A. 单一主视觉

- 让“在技术与想象之间，建立自己的宇宙。”成为首屏唯一一级标题和最高对比文本。
- 将轨道核心移入标题构图或置于标题背后偏右，成为空间氛围与视线引导，不再作为等权独立栏目。
- 保留一处高饱和青色信号和一处蓝紫体积光，其余发光降级。

### B. 明确阅读路径

- 首屏顺序固定为：身份短标签、标题、短介绍、主按钮、次入口。
- “阅读博客”使用清晰的实心或高对比按钮；“GitHub”改为弱化文本入口。
- 删除或移出首屏的非必要信息：坐标、年份、重复 ONLINE、不可读 HUD 标签。若保留，只能作为纯装饰且不得承担理解任务。
- 首屏下沿加入低干扰的继续探索提示。

### C. 提升可读性

- 调整颜色变量，正文目标对比度 `>= 7:1`，交互文字 `>= 4.5:1`。
- 正文桌面 `>= 16px`、移动 `>= 15px`，导航和按钮 `>= 13px`，功能性辅助文字 `>= 12px`。
- 中文正文使用稳定的系统字体栈；展示字体只用于品牌与大标题。
- 暗色卡片必须通过边界、层级或明度区分，不用“更暗的字”制造层级。

### D. 惊艳但克制

- 用轨道切线、局部遮挡和大留白形成动漫分镜感，不引入角色或版权素材。
- 首屏入场动效总时长控制在约 `800ms`，主要内容不能等待动效结束才可读。
- 保持纯 CSS / Canvas 2D，不引入 Three.js、React 或大型动效库。
- 遵守 `prefers-reduced-motion`，关闭 JavaScript 时标题、正文和链接仍然可用。

## 验证矩阵

1. 运行类型检查、单元测试、生产构建和 E2E。
2. 在 `360x800`、`768x1024`、`1440x900`、`1728x1117` 检查首屏；无横向滚动和文字裁切。
3. 首屏无需滚动即可看到完整标题、介绍和“阅读博客”；移动端至少可看到主按钮。
4. 用自动化断言检查关键功能文字的最小字号和颜色对比度；不得只凭肉眼判断。
5. 键盘 Tab 顺序先经过品牌/导航，再到博客主操作和 GitHub；焦点清晰。
6. 开启减少动态后，内容立即稳定可读，轨道无持续运动。
7. 浏览器视觉验收分别记录桌面与移动端结果；截图只作为视觉证据，不替代功能测试。
