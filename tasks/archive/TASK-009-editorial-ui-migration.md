## 设计意图

- 保留 Orbitvo 的科技、艺术与克制动效，将纯深色宇宙改为有呼吸感的浅色编辑布局。
- 立体星芒是唯一首屏主视觉，标题、说明、博客与 GitHub 仍是首要信息。
- 支持浅色 / 深色主题，并修正设计稿中的对比度、字号、焦点和触控尺寸问题。
