# history

| 目录 | 内容 |
| --- | --- |
| `demos/` | 视觉探索稿（F Constellation、favicon 选项、星图志示例等） |
| `backups/` | 迁移前网站备份（Quiet Lumen 生产 + F demo） |
| `docs/` | 历史文档与视觉基线 |
| `artifacts/` | 任务验收截图 |
| `tasks/` | 任务队列（`active/` / `archive/`） |
| `个人网站设计/` | 早期 Figma Make / Vite React 稿 |

当前生产站源码仍在仓库根目录的 `src/`、`public/`。
