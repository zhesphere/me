## 目标

仅在现有手机断点内重新整理 Hero 的纵向节奏：保持文字与行动入口优先阅读，同时缩短 GitHub 与轨道之间的空白，让 ORBITVO 核心更早、更完整地进入常见手机浏览器视野。桌面端视觉必须保持现状。

## 已确认根因

- 980px 以下已经使用 `min-height: auto`，因此当前问题不是固定 `100vh` 或动态工具栏直接造成。
- 宇宙视觉在移动端仍处于正常文档流，没有继承桌面的绝对定位。
- 700px 以下 Hero 使用 `30px` 网格间距；430px 以下 CTA 改为纵向，但间距没有随构图收紧。
- 430px 以下轨道从 `88vw` 放大为容器宽度的 `96%`；方形容器使核心中心进一步下移，容易进入浏览器底部工具栏遮挡区。

## 允许修改范围

- `src/styles/global.css` 中既有 `max-width: 430px` 手机断点的 Hero 布局规则。
- `tests/e2e/home.spec.ts` 中与本任务直接相关的移动端几何回归测试。
- 本任务文件与 `PROJECT_HUB.md`。

- 不修改首屏以外区域，不新增内容、卡片、空链接或依赖。
